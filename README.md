# React-Native-MobileApp
chat Application build with React Native and TypeScript
# yarn install
- To Install node modules 
# for Ios
- cd ios && pod install (make sure you have cocopods installed)
# run the app
- yarn start to start the metro bundler
- yarn run ios (for ios) / npx react-native run-ios
- yarn run android (for android) / npx react-native run-ios

# Freatures
- SignUp using firebase authentication
- login with credentials/ with google/ with facebook
- react-native-bootsplash for splash screen
- zustand for state management
- AsyncStorage to save the Auth status
- react-native-gifted-chat for chat screen
- FireStore as a DB.
